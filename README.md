# Linear Clone Repository

This repository has been trimmed to contain only the `sites/linear` project.

## Contents

- `sites/linear/` — the Linear simulation site and standalone Next.js app

## Run locally

```bash
cd sites/linear
npm install
npm run dev
```

Open `http://localhost:3000` once the dev server starts.

- All other monorepo packages and sites have been removed.
